# Data release statement

The data package in `data/`—the 212 selected right-eye images, patient metadata, labels, and derived ResNet-50 features—was supplied through the collaborating hospital project for the associated PROP study.

The project maintainer confirms that this selected package may be publicly distributed with this research repository. This statement covers inclusion of the study subset and its derived files in the repository. Users should cite the associated PROP paper and the cataract_patient_dataset data provenance when reusing the data.

This file records the project-level publication permission; it does not alter the ownership or provenance of the underlying clinical research data.
